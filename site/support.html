Support

Voice Command AI is open source. Help, bug reports and feature requests go through the project's GitHub repository.

Get help

  • Read the user guide: install, pair a phone, talk to your agents and reach your PC from outside.
  • Check Troubleshooting for common problems, such as pairing links that expire, speech errors and connection issues.
  • Search or open an issue on GitHub Issues. Say which app and version you use (Settings → About), your operating system, and what you expected to happen.

Open GitHub Issues

Sending a diagnostic log

If we ask for a diagnostic log, turn it on in Settings → About → Diagnostic log, reproduce the problem, then press Copy. The log is off by default, stays on your device and is never uploaded; it holds timings, counts, status and error codes, not audio, transcripts, prompts, file paths, keys or addresses. You decide whether to send it.

GitHub issues are public. Read the log before you paste it, and never post keys, tokens, authenticator codes or personal data in an issue. Turning the log off clears it.

Security problems

Do not report a security or privacy vulnerability in a public issue. Use private vulnerability reporting as described in the security policy.
