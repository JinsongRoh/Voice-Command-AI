Why VCA

Many agents. One keyboard. Something gives.

Parallel agent sessions bring sub-agents, compilers, test runners and helper windows onto one workstation. Three things break first.

  • Focus theft

    New windows keep stealing focus, so prompts and keystrokes land in the wrong terminal.

    With VCA

    Commands go straight to the target session through a virtual terminal. No simulated keystrokes.

  • Resource exhaustion

    Agents start builds and tests without knowing about each other, until CPU and memory are saturated and the machine stalls.

    With VCA

    A resource broker admits heavy jobs into a set number of slots and queues the rest.

  • Navigation overhead

    Remote-control apps make you drill into one project, back out and drill into the next, for every command.

    With VCA

    Every session sits on one deck of cards. Pick one, speak, send.

Features

What works in the pre-release today

Built from source and running end to end. Items marked “Coming soon” are not available yet.

  • Session cards

    Every agent session on your machine as a live card: project, agent, status and alerts at a glance.

  • Voice first

    Tap and speak. Live dictation streams as you speak; review the text, then send. A developer-vocabulary engine keeps technical terms intact.

  • No focus required

    Commands reach the target session through a virtual terminal or the agent’s own channel, never through simulated keystrokes.

  • Live view

    Follow any session as a readable chat view or the raw terminal, and keep the conversation going from there.

  • Alerts

    Know when a session finishes, needs input or asks for a decision, and answer with one tap.

  • Resource broker

    CPU, memory, disk and network per session. Heavy jobs are admitted, queued, throttled or paused by your policies.

  • Multiple machines

    Pair your home, office and server machines with one app.

  • Pairing and encryption

    One-time pairing links, TOTP two-factor sign-in, short-lived tokens, Noise end-to-end encryption, an audit log and a kill switch.

  • Your choice of connection

    Direct LAN, Tailscale, Cloudflare Tunnel or your own provider. The server listens only on localhost until you pick one.

  • Pluggable speech-to-text

    Any OpenAI-compatible speech server, such as a Whisper server you run yourself, or OpenAI and Google Cloud.

  • Coming soon

    Multi-agent orchestration

    Coordinate several sessions on one task through an optional orchestrator session.

  • Coming soon

    DNSPilot connectivity

    Reach your machine through DNSPilot, by tunnel or peer-to-peer, as one more optional provider.

How it works

Your phone talks only to your machine.

After a one-time pairing, the app connects to the VCA server on your machine over an end-to-end encrypted Noise channel. The server owns the agent sessions. Nothing goes through a VCA cloud.

  1. Run your agents under VCA

    Managed sessions accept input from the app without touching window focus.

    vca run -- claude

  2. Pair once

    Open the one-time pairing link on your phone and enter the 6-digit code from your authenticator app.

    vca pair

  3. Pick a card and speak

    Choose the session, dictate, check the target and the text, then send.

Measured in M0

Numbers from real machines.

Milestone M0 tested each building block on Windows, macOS, Linux and an iPhone in October 2026. A few results:

  • 7,199 / 7,199 requests answered in a 2‑hour soak over LAN and over Tailscale, with none lost
  • 1.3 s to reconnect after a server restart, with no re-pairing
  • ~0.3 s to transcribe about 10 s of speech on a GPU Whisper server
  • 5.5 ms median round trip on a LAN through the encrypted channel
  • Managed sessions verified on Windows and macOS
  • Real Claude Code hooks and Codex input
  • Admission control with real cargo builds
  • iPhone voice input to transcript

Not yet run in M0: Cloudflare Tunnel and DNSPilot connections, Android builds and cloud agent APIs. Read the M0 report

Try it

No installers yet. Build it in a few commands.

Install the server and the CLI from source, start the server, and run your first agent under VCA.

Requires Git and the Rust toolchain. On Windows, also the “Desktop development with C++” build tools.

$ git clone https://github.com/JinsongRoh/Voice-Command-AI.git
$ cd Voice-Command-AI && git checkout dev/m0-foundation
$ cargo install --path crates/vca-server   # vcad
$ cargo install --path crates/vca-cli      # vca
$ vca daemon
$ vca run -- claude
