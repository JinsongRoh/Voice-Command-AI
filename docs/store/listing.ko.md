## 전체 설명 (App Store, Play, 4000)

Voice Command AI는 내 컴퓨터에서 실행 중인 모든 AI 코딩 에이전트를 주머니 속으로 가져옵니다. 세션마다 실시간 카드로 보고, 하나를 골라 말하면 그 말이 해당 세션으로 바로 전달됩니다. 키보드 포커스를 맞출 필요도, 다른 창이 입력을 가로챌 걱정도 없습니다.

Voice Command AI는 컴패니언 앱입니다. 내 Windows, Mac 또는 Linux 컴퓨터에서 실행되는 무료 오픈소스 Voice Command AI 서버(vcad)에 연결됩니다. Voice Command AI 클라우드도, 회원 가입도 없습니다. 세션, 음성, 키는 내 휴대폰과 내 컴퓨터 사이에만 머뭅니다.

세션 카드
- 컴퓨터의 모든 에이전트 세션을 실시간 카드로: 프로젝트, 에이전트, 상태, 알림, 실행 중인 하위 에이전트.
- 프로젝트 폴더에서 새 세션을 시작하거나 이미 열려 있는 세션을 이어받기.
- 어떤 세션이든 읽기 쉬운 채팅 화면이나 원본 터미널 화면으로 실시간 보기.

음성 우선
- 마이크를 누르고 말한 뒤, 받아쓴 내용을 확인하고 보내기.
- 손이 바쁠 때는 핸즈프리 모드와 "보코(Voco)" 호출어.
- 여러 언어가 섞인 말과 개발 용어에 맞춘 어휘.
- 음성 인식은 내가 컴퓨터에 설정한 엔진에서 처리: 직접 운영하는 서버나 내 클라우드 계정.

바로 처리할 수 있는 알림
- 결정이나 입력을 기다리는 모든 세션을 한 목록에서, 한 번의 탭으로 응답.
- 기기 음성이나 내 TTS 엔진으로 듣는 음성 알림과 상황 브리핑.
- 에이전트가 직접 해 달라고 요청한 일을 모은 할 일 목록.

휴대폰에 맞춘 설계
- 세션 사이를 스와이프로 이동하고, 사진을 첨부하고, 라이트·다크·블랙 테마 선택.
- 집, 사무실, 빌드 서버 등 여러 컴퓨터를 앱 하나에 연결.
- 관리자 기기 전용 원격 셸: 생체 인증 잠금과 인증 앱 코드로 보호.

안전한 설계
- 컴퓨터에 표시된 QR 코드를 스캔해 연결.
- 로컬 네트워크, VPN, 직접 고른 터널 등 어떤 경로로 연결하든 휴대폰과 컴퓨터 사이는 종단 간 암호화.
- 컴퓨터 쪽의 짧은 수명 토큰, 2단계 인증, 감사 로그, 긴급 차단 스위치.
- 분석 도구, 광고, 추적 없음.

필요한 것
- Voice Command AI 서버(무료, 오픈소스)가 실행 중인 컴퓨터.
- 그 컴퓨터에 설치된 AI 코딩 에이전트.
- 음성 입력을 쓰려면 컴퓨터에 설정한 음성 인식(STT) 엔진.

Voice Command AI는 MIT 라이선스의 오픈소스입니다.

## 0.1.0의 새로운 기능

첫 출시입니다.
- 내 컴퓨터의 AI 코딩 에이전트를 보여 주는 실시간 세션 카드.
- 탭해서 받아쓰기, 핸즈프리 모드, 보코(Voco) 호출어로 음성 입력.
- 한 번의 탭으로 답하는 알림, 음성 브리핑, 할 일 목록.
- QR 연결, 종단 간 암호화, 생체 인증 앱 잠금.
