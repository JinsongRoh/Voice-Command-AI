# Voice Command AI (VCA) logo SVG package v1.0

Based on the [VCA brand definition v1.0](../brand-definition.md).

| Folder | Contents |
|---|---|
| `01_symbol` | The symbol alone (transparent background, 0.20S clear space on every side) |
| `02_lockups` | Horizontal, vertical and abbreviated (VCA) lockups × 7 color combinations: dark-gradient, light, on-navy-white, on-blue-white, white-transparent, mono-black, mono-navy. `horizontal/VCA_logo_horizontal_dark-transparent.svg` is dark-gradient without its navy background, for dark pages (GitHub dark mode) |
| `03_background_variants` | Background variants 01–06 (1200 × 750) |
| `04_app_icon` | 1024 master (full square; the OS applies the mask) and a solid version |
| `04_app_icon/android_adaptive` | Foreground (108 dp canvas, inside the 66 dp safe zone), background and monochrome layers |
| `04_app_icon/preview` | iOS corner preview (not for distribution) |
| `04_app_icon/small` | 48 / 32 / 24 px icons, a 16 px favicon and a transparent favicon |
| `05_collateral` | Stickers (blue, navy) |

The top-level `VCA_logo_*_{dark,light}.svg` files are the main horizontal, vertical and abbreviated logos; `VCA_logo_original.svg` is the original symbol artwork.

**Colors:** Command Blue `#0361F7` · Deep Navy `#101B35` · Voice Cyan `#00CFE8` · Light Blue `#DCE6F7`.

**Wordmark:** outlined; placeholder typeface Noto Sans Bold, to be replaced with Inter Semibold.

**Note:** the 16 px favicon is a basic simplification; optical correction on real devices is recommended.
