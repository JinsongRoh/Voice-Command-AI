# Voice Command AI Brand Definition

> **Your voice. Every agent. One command center.**

- Version: v1.0 (2026-10-30)
- Design basis: a symbol made of the **V of Voice and a voice waveform**
- Status: proposed brand guidelines. Product descriptions describe the target experience.
- Full edition with page layouts: [VCA_Brand_Definition_v1.0_EN.pdf](VCA_Brand_Definition_v1.0_EN.pdf) ([PPTX source](VCA_Brand_Definition_v1.0_EN.pptx)). Logo files: [logo/](logo/README.md).

## 1. Brand definition

Voice Command AI turns a developer's voice into clear commands and manages the flow of many AI coding sessions in one place.

| Item | Definition |
|---|---|
| Name | Voice Command AI |
| Short name | VCA |
| Category | Voice-driven remote control and orchestration of AI coding agents |
| Audience | Developers and teams running several projects, sessions and machines at once |
| Problem | Keyboard-focus conflicts, resource contention, and the cost of switching sessions and checking their state |
| Promise | You always see which session gets which instruction before it runs. |
| Values | Clarity · Control · Connection · Openness |

## 2. Messaging and voice

**Slogan:** Your voice. Every agent. One command center.

**One-line description:** A tool to check and direct the AI coding sessions on your development machine by voice, from your phone.

**Tone:**
- Short and specific.
- Show the target, the action and the result first.
- Put the user's sense of control first.
- Keep the current state and the choice needed clearly apart.
- Claims about security, connectivity or free use only as far as the implementation and terms confirm them.

| Situation | Recommended wording |
|---|---|
| Command review | Check the command for Codex in DNSPilot. |
| Completion | Tests finished. Review the 2 failed items. |

## 3. Symbol

| Element | Meaning | Form |
|---|---|---|
| V / Voice | The first letter of Voice | A V outline opening to both sides |
| Wave / voice signal | The human voice and the input signal | Five rounded strokes of different heights |
| Control | The work of many agents managed in one place | A rhythm converging to the center |

The chosen original is the V-shaped waveform with a blue-to-cyan gradient on a navy background. The applied examples are vector interpretations that explain the rules; final production aligns curvature, spacing and gradient to the original.

## 5. Color and type

| Color | HEX | Role |
|---|---|---|
| Command Blue | `#0361F7` | Main brand color, primary actions, single-color symbol |
| Deep Navy | `#101B35` | Dark backgrounds, primary text |
| Voice Cyan | `#00CFE8` | Waveform and voice-input accents |
| Cloud White | `#F5F7FB` | Light backgrounds |

- Proportion: navy and white 80%, blue 15%, cyan 5%.
- Signature combination: navy background with the blue-cyan symbol.
- On light backgrounds, prefer single-color blue.
- Never use cyan for small body text.
- Gradients are for emphasis; the single-color version is the production master.

| Use | Typeface | Weight |
|---|---|---|
| Korean | Pretendard | Headings Semibold, body Regular |
| Latin | Inter | Headings Semibold, body Regular |
| Status and figures | The body typeface of the language | Medium |
| Code | JetBrains Mono | Regular |

The wordmark keeps fixed proportions. In the current SVG package it is outlined from Noto Sans Bold as a placeholder until it is redrawn in Inter Semibold.

## 7. App icon and small sizes

- Place the symbol at about 65–70% of the square canvas.
- Masters for OS-masked icons are full squares; don't pre-cut the corners.
- Android adaptive icons keep foreground and background separate.
- Check the visible area against each platform's template.
- Consistency of the symbol comes before platform-specific outlines.

| Item | Guideline |
|---|---|
| Minimum symbol size | 24 px |
| Minimum print size | 8 mm |
| 16 px favicon | Optical correction recommended |
| Keep when small | The five strokes and the V outline |
| Drop when small | Gradient and gloss |
| Review | Check legibility on real devices |

## 8. Digital touchpoints

| Touchpoint | Application |
|---|---|
| App header | Symbol + "Voice Command AI", with machine name and connection state |
| Voice input and command review | Show the target session and project clearly |
| Notifications | Abbreviated icon + task state + an action to review the result |
| Connection state | Text together with a status indicator |

**State colors:** running = blue, done = green, input needed = amber, error or emergency stop = red. Always pair color with text or an icon; never recolor the logo by state. Exact HEX values for state colors are not fixed by this definition.

**Motion:**
- Recording: the waveform amplitude moves smoothly.
- Sending: one converging motion.
- Idle: the logo stays still.
- Accessibility: respect the reduced-motion setting.

## 10. Usage rules and production checklist

**Clear space:** with the symbol width as `S`, keep at least `0.20S` free on every side. The gap to the wordmark is about `0.18S`, adjusted optically. Clear space is the margin around the symbol, not the safe area inside an app icon.

**Don't:**
- stretch or squash the logo
- rotate it
- change the number of strokes
- add outlines
- add heavy shadows or gloss
- place it directly on busy photos
- use low contrast
- put letters inside the symbol

| Asset | Specification |
|---|---|
| Logo | SVG / PDF vectors, RGB single-color and reversed versions |
| App icon master | 1024 × 1024 PNG |
| Platform icons | Exported separately per platform specification |
| Masters | Gradient original and single-color master kept apart |
| Print | Convert to CMYK with the output profile, then proof |

**Checklist:**
- [ ] Legible at 24 px?
- [ ] Enough contrast on dark and light backgrounds?
- [ ] Five strokes and the V outline intact?
- [ ] Within the OS mask safe area?
- [ ] Wording matches what the product really does?
- [ ] State explained by text or an icon, not color alone?
