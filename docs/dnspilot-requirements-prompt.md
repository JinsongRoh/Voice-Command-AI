# DNS Pilot 연동 요구사항 (DNS Pilot 개발용 프롬프트 초안)

> 상태: 초안 v0.1 — DNS Pilot 기능 정의서를 받은 뒤 이미 있는 기능과 새로 필요한 기능을 구분해 갱신한다.

---

## 프롬프트 본문

당신은 DNS Pilot(DDNS + 사설 터널 서비스)의 개발자다. 오픈소스 프로젝트 **Voice Command AI**(이하 VCA)가 DNS Pilot을 기본 원격 접속 수단으로 쓰려고 한다. VCA는 다음과 같이 동작한다.

- 사용자 PC에 상시 실행되는 Rust 에이전트(VCA Server)가 있다.
- 모바일 앱(VCA Mobile)이 외부에서 그 PC에 접속한다.
- 접속 후 Claude Code·Codex·Gemini CLI 같은 코딩 에이전트 세션을 음성으로 제어한다.

아래 요구사항을 검토해 이미 지원하는 항목, 개발이 필요한 항목, 불가능한 항목으로 분류하고 각 항목의 API·SDK 설계안을 제시하라.

### 1. 사설 터널
- 사용자 PC의 로컬 서비스(예: `127.0.0.1:47800`)를 포트포워딩 없이 외부에 노출한다. CGNAT, 회사 방화벽, 이중 NAT 환경도 지원해야 한다.
- 프로토콜:
  - HTTPS와 WebSocket을 필수로 지원한다. 장시간 연결과 양방향 실시간 스트리밍이 필요하다.
  - (선택) 원시 TCP와 QUIC를 지원한다.
- 지연 시간 목표: 같은 지역 기준 터널 왕복 추가 지연 50ms 이하. 음성 명령 응답성과 터미널 스트리밍 품질에 영향을 준다.
- 연결 품질:
  - 끊기면 자동으로 재연결하고, 재연결 동안 세션을 유지한다.
  - 하트비트를 보내고 연결 상태 이벤트를 제공한다.
- 사용자마다 고정 서브도메인을 준다(예: `<user>.<pc-name>.dnspilot.app`). 인증서는 와일드카드 등으로 자동 발급하고 갱신한다.

### 2. 로컬 연동 API / SDK (VCA Server → DNS Pilot Agent)
- VCA가 DNS Pilot Agent를 프로그램으로 제어할 수 있는 로컬 API를 제공한다. localhost 전용으로 하고 로컬 토큰으로 인증한다.
  - 터널 생성, 조회, 삭제, 일시 중지
  - 공개 URL과 상태 조회
  - 이벤트 구독: 연결, 해제, 외부 접속 시도
- Rust 크레이트 또는 OpenAPI 명세를 제공한다.
- CLI를 제공한다(예: `dnspilot tunnel open --port 47800 --name vca`).
- Agent 설치 여부와 버전을 감지하는 방법, 그리고 VCA 설치 마법사에서 쓸 로그인·연동 흐름(디바이스 코드 방식 등)을 제공한다.

### 3. 터널 레벨 보안
- 터널 앞단에서 접근 통제를 할 수 있어야 한다. VCA 자체 인증과 별도로 겹겹이 막기 위함이다.
  - 허용 기기 목록(기기 인증서·mTLS 또는 기기 토큰)
  - IP와 국가 기반 허용·차단 (선택)
  - 요청 속도 제한, 무차별 대입 차단
- **킬 스위치 API:** 호출 즉시 터널을 닫고 기존 연결을 모두 끊는다. 웹 콘솔과 모바일에서도 실행할 수 있어야 한다.
- **접속 감사 로그:** 시각, 출발 IP, 기기 식별자, 결과를 남긴다. 조회 API를 제공한다.
- **새 기기·새 위치 접속 알림:** 웹훅이나 푸시로 보낸다.
- 터널 운영자(DNS Pilot)가 내용을 볼 수 없는 종단 간 암호화를 지원할지 여부와 방식을 명시한다(TLS 패스스루 등).

### 4. 푸시 알림 중계
PC는 APNs/FCM으로 직접 푸시를 보낼 수 없으므로 DNS Pilot이 중계한다.

- 모바일 앱이 자신의 푸시 토큰을 DNS Pilot 계정·PC에 등록하는 API
- VCA Server가 푸시를 요청하는 API
  - 입력: 대상 기기, 제목, 본문, 데이터
  - 우선순위와 소리 옵션
- 푸시 본문은 VCA가 **종단 간 암호화한 페이로드**로 보내고, 중계 서버는 내용을 보지 않는다. 앱이 받아서 복호화하는 방식을 지원해야 한다.
- 계정당 발송 한도와 실패 재시도 정책을 정한다.
- iOS와 Android를 모두 지원한다. VCA 앱의 번들 ID와 인증서를 등록하는 절차도 필요하다.

### 5. 다중 PC 관리
- 한 계정에 PC 여러 대를 등록하고 각 PC의 터널 상태와 온라인 여부를 조회하는 API를 제공한다.
- 모바일 앱이 계정에 등록된 PC 목록을 받아와 선택해서 접속할 수 있어야 한다.

### 6. 상업·오픈소스 정책
- VCA 사용자용 무료 제공 범위와 유료 전환 지점을 정한다(트래픽, PC 수, 푸시 수 등).
- 오픈소스 코드에 넣을 수 있는 공개 클라이언트 ID와 API 사용 약관을 마련한다.
- 서비스 장애 시 동작을 정의한다. 예: VCA가 Tailscale·Cloudflare Tunnel 같은 대체 수단으로 넘어갈 수 있도록 상태 API를 제공한다.
